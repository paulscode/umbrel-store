Electrs Pruned

An Electrum server indexing your pruned Bitcoin node.

Connect a wallet on your network

Point any Electrum-compatible wallet at your Umbrel, on port 50201, using plaintext TCP rather than SSL.

<your-umbrel-address>:50201:t

In Sparrow that is Preferences, then Server, then Private Electrum, with "Use SSL" off. In Electrum it is the host:50201:t form above.

Connect another Umbrel app

Declare a dependency on this app and read the endpoint it exports:

APP_ELECTRS_PRUNED_SERVER_IP
APP_ELECTRS_PRUNED_SERVER_PORT

While it is indexing

The first sync builds an address index over the whole chain and takes hours. Wallets can connect before it finishes, but balances are only correct once it catches up.

Blocks your node has pruned are fetched from the peer-to-peer network and checked against your node before use, so a wallet asking about very old transactions waits for a network round trip. Recent history is unaffected.
