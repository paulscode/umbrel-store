Bitcoin Knots BLAKE2b

The node is running. There is nothing to see here, and that is normal.

A Bitcoin node has no web interface. This page exists because every Umbrel app needs something behind its Open button.

What this app does is run a private test chain that enforces the proposed BLAKE2b proof-of-work rules, so a BLAKE2b ASIC can mine blocks a Bitcoin node accepts. To actually mine, you need the other half:

  1. Install Datum Gateway BLAKE2b from the same app store.
  2. Open it. It will show you the address to point your miner at, and it will ask this node for a payout address on its own.
  3. Point your miner at that address, using your server's IP rather than a .local name, and watch the dashboard.

This is not Bitcoin. It is regtest: a private chain that starts empty and has no peers. The coins it mines are worthless by construction and cannot be sent anywhere. BLAKE2b is a proposal that Bitcoin has not adopted, and this app exists to answer a hardware question, not to mine anything of value.
